Learning outcome 04 / Learning

Explain fundamental machine learning approaches and distinguish between major learning paradigms.

My evidence

I understand machine learning as a way for computers to learn from data or experience instead of having someone program a rule for every situation. This connects to my interests in robotics, basketball, and building my own AI assistant. For example, a basketball training system could learn to recognize different movements from video examples. The information it uses, such as a player’s position or shooting angle, is called features. The goal is generalization, meaning the model can apply what it learned to new examples. If it performs well on its training examples but struggles with new videos, that is called overfitting. Supervised learning involves training a model with labeled data, which means the examples include the correct answers. For my basketball training project, I could label shots as makes or misses so a model could learn to classify new shots. This is classification because the output is a category. If I wanted to predict a numerical value, such as how far a shot will travel based on its release speed and angle, that would be regression. Both tasks involve learning a relationship between the inputs and a known output. Unsupervised learning looks for patterns in data without being given the correct answers. For example, I could give a model basketball statistics and use clustering to group players with similar shooting, passing, and defensive performance. I would not tell the model which players belong in each group beforehand. This could help me discover different playing styles and understand similarities that might be difficult to notice by looking through the statistics myself. Reinforcement learning is about learning through actions and their consequences. I connect this to a robot learning how to move through a room. The robot is the agent, the room is its environment, and its available actions could include moving forward or turning. It could receive a positive reward for reaching its destination and a penalty for hitting an obstacle. Over repeated attempts, it learns a policy, which is a strategy for choosing actions that maximize its expected total reward. A method like Q-learning estimates how valuable an action is in a particular state. The robot must balance exploration, or trying unfamiliar actions, with exploitation, or using actions it already expects to work well. The main difference between these approaches is how the system learns: supervised learning uses labeled examples, unsupervised learning finds patterns without labels, and reinforcement learning uses rewards from interacting with an environment. Deep learning uses neural networks with multiple layers and can work within these different paradigms. For my projects, the approach I choose would depend on whether I have labeled examples, want to discover patterns, or need an agent to learn how to act.
