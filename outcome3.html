Learning outcome 03 / Techniques

Describe how core AI techniques such as search and adversarial reasoning are used to model intelligent behavior.

My evidence

Core AI techniques such as search and adversarial reasoning model intelligent behavior by allowing an agent to evaluate possible actions and choose how to reach a goal. Search represents a problem as a state space, with an initial state, available actions, transitions between states, and a goal test. This connects to my interest in robotics and my AI companion project: a robot navigating a room could represent its position as a state and its movements as actions. Breadth-first search (BFS) explores states level by level and finds the shortest path when all movements have equal cost, while depth-first search (DFS) explores one branch deeply before backtracking. A* search uses both the cost already traveled, (g(n)), and a heuristic, (h(n)), that estimates the remaining cost. Its evaluation function, (f(n)=g(n)+h(n)), helps prioritize promising routes. Adversarial reasoning models decision-making when an opponent’s actions affect the outcome. This relates to my interest in basketball and soccer, where choosing an action requires anticipating how a defender might respond. In a simplified basketball simulation, an agent could consider shooting, passing, or driving, then evaluate possible defensive responses using a game tree. Minimax selects the action with the best outcome assuming the opponent chooses the strongest response, while a utility function assigns values to outcomes. Alpha-beta pruning improves efficiency by skipping branches that cannot change the minimax decision. Although real sports involve uncertainty and simultaneous actions, this model illustrates how an agent can plan beyond its immediate move. Together, search and adversarial reasoning demonstrate intelligent behavior through goal-directed planning, evaluation of alternatives, and anticipation of consequences.
